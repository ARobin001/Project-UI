# Project-UI

明德AI知识操作系统的中文界面设计与交互原型。

[查看新版界面截图](./designs/knowledge-ui/v2/README.md) · [界面规范](./designs/knowledge-ui/DESIGN-SYSTEM.md) · [开发运行说明](./DEVELOPMENT.md)

## 运行

```bash
npm ci
npm run dev
```

使用 Node.js 20.19+ 或22.12+。生产构建运行 `npm run build`。

## 页面范围

- 知识中心：知识库发现、类型与关系筛选、收藏及创建。
- 知识库工作空间：分类、搜索、资料双状态和批量选择。
- 资料详情：概览、原文、AI理解、证据、版本和资料信息。
- AI整理中心与问明德AI：示例任务与单资料范围问答。

原型采用示例数据，没有接入真实后端。新添加的资料仅保存本地记录，不上传文件或自动成为可检索内容。证据与原文联动用于交互展示；当前不提供审核、发布、版本比较或回滚。
